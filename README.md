# 3209 Transfer Score Tracker

Daily snapshot viewer for Server 3209's top-100 transfer scores, in Chinese / English / Russian.

Internal tool for NAP alliance officers. Data is scraped from the public [wos oracle](https://wos.oracle) leaderboard; this site just organizes it and tracks day-over-day growth.

**Not indexed** (robots.txt + meta noindex). Share via direct link.

## Updating

Replace `data.js` with the latest build and push. GitHub Pages redeploys in ~1 minute.
